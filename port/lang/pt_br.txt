# Brazilian Portuguese (PT-BR) text for the port.
#
# The game itself never shipped in Portuguese, so this text is the port's own:
# it is drawn instead of the English text while the game runs in English, and
# neither the ROM nor gLanguage change (RetroAchievements identify the game by
# the ROM's hash and read its RAM; both stay those of an English game).
# It is offered with the EU ROM only, next to the five languages it carries.
#
# tools/lang/gen_lang.py turns this file into port/generated/lang_pt_br.c.
# Run it after every edit (it also checks that each line fits on screen):
#
#     python tools/lang/gen_lang.py
#
# Format
#   [ENUM_NAME]          starts an entry; the name is the game's own constant
#                        (MESSAGE_*, LT_*, DESCRIPTION_TEXT_*, STORY_TEXT_*,
#                        FILE_SCREEN_TEXT_*). An entry that is missing here
#                        keeps the English text.
#   following lines      the text, one screen line per line, in the same
#                        escapes as src/data/text_data.c ({COLOR(5)},
#                        {B_button}, ...). Blank lines inside an entry are
#                        dropped; a line that is just "{GAP(110)}" is the
#                        empty second line single-line messages have.
#   {CENTER}             at the start of a line: centred the way the English
#                        text centres that line (the GAP is worked out from
#                        the font widths). Emits nothing where the English
#                        line is not centred.
#   # ...                a comment line.
#
# Glossary (kept the same in the text and in the graphics):
#   Energy Tank = Tanque de Energia      Missile = Míssil
#   Super Missile = Supermíssil          Power Bomb = Bomba de Poder
#   Long Beam = Raio Longo               Charge Beam = Raio Carregado
#   Ice Beam = Raio de Gelo              Wave Beam = Raio de Ondas
#   Plasma Beam = Raio de Plasma         Bomb = Bomba
#   Varia Suit = Traje Varia             Gravity Suit = Traje Gravitacional
#   Morph Ball = Bola Morfo              Speed Booster = Acelerador
#   Hi-Jump = Supersalto                 Screw Attack = Ataque Giratório
#   Space Jump = Salto Espacial          Power Grip = Pegada Firme
#   Power Suit = Traje de Poder          Mother Ship = Nave-Mãe
#   Space Pirates = Piratas Espaciais    Time Attack = Contrarrelógio
#   Save = Salvar                        hatch = escotilha
#   Area and boss names (Brinstar, Kraid, Mother Brain, Chozo...) stay as they are.
