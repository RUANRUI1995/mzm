- Saves: mzm.sav is now a real GBA save (32 KB). Copy a save from a GBA emulator or cartridge into the game folder as mzm.sav and it loads, from any region's ROM, and yours works in an emulator. Your current save is converted the first time you start this version; the old file is kept as mzm.sav.legacy.
- Button remapping only changes the controls while you play: menus, the pause screen and messages use the normal buttons again. MORPH BALL IN/OUT does nothing until you have the Morph Ball.
- New option CHARGE PULLS DROPS (in the controls list): while the Charge Beam charges, nearby energy and ammo drops fly to Samus. Off by default.
- WIDE: Samus's close-up when she lands no longer shows broken copies at the sides. With WIDE + AI it gets a full picture around it.
